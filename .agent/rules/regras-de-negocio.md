Antes de qualquer ajuste ou nova feature que envolva pontuação, palpites, partidas,
fases, odds, ligas, ranking ou notificações, leia `REGRAS_DE_NEGOCIO.md` na raiz do
projeto. Ele é a fonte de verdade das regras de negócio e prevalece sobre o código,
o README e os scripts SQL soltos.

Se o pedido conflitar com uma regra desse arquivo, pare e pergunte antes de alterar.
Quando uma regra mudar com aprovação, atualize `REGRAS_DE_NEGOCIO.md` no mesmo commit
(incluindo o "Histórico de decisões") e todos os lugares do "Mapa de implementação".
